# Pilot Proposal (draft — for a named EPHI/APHI counterpart)

- **Problem:** public outbreak signals in Ethiopian languages reach PHEM analysts late and unstructured.
- **Pilot:** 4–8 weeks, one unit, **public data only**, synthetic-data demo first.
- **Metrics:** signal-to-verification time, queue precision (confirmed ÷ queued), de-duplication reduction.
- **Compliance:** no patient data; Proclamation 1321/2024 note in `data-governance.md`; all code and results public.
- **Ask:** a named counterpart, lexicon validation, and permission to run in shadow mode.
