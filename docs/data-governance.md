# Data Governance

- **Ethiopia Personal Data Protection Proclamation 1321/2024:** health data is sensitive personal data.
  Signal-Am's defence is architectural — it collects none. Public posts are minimised: no author profiles
  stored beyond source name; no personal identifiers in exports.
- **African Continental Health Data Governance Framework** (validated Addis Ababa, 22 Oct 2026): federated,
  sovereign model — data stays in-country, tools plug in, nothing is extracted to foreign cloud.
- Audit log is append-only. Breach process: maintainer notifies repository owner within 72h of discovery;
  because no personal data is stored, breach surface is limited to system credentials, which are never in the repo.
- Do-no-harm: exports are labelled *unverified signal* until EPHI verifies them in their own system.
